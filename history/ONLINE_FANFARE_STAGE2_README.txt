大集合：ファンファーレ共通化 Stage 2

今回の追加
1) キュアレモネード（オンライン）
- 発動したプレイヤーが1〜7から重複なしで2つ選択。
- 確定するまでゲームを停止。
- 確定した2数字は場が流れるまで全プレイヤーのプレイを禁止。
- 禁止数字はFirebase経由で全端末に同期し、場が流れた時に解除。

2) お父様（オンライン）
- 発動したプレイヤーが1〜7から数字を1つ選択。
- その数字のフォロワーだけを自分の手札から一覧表示。
- 0〜4枚を選択して破壊。0枚でも確定可能。
- 選択UIは発動者の端末だけに表示し、他の端末は効果処理待ち。
- 破壊結果と墓地移動はFirebase経由で全端末に同期。

COMの場合
- キュアレモネードは数字をランダムに2つ選択。
- お父様は数字をランダムに1つ選び、該当カードを最大4枚まで自動破壊。

同梱
- index.html：Stage 1のソロ版（既存の動作を維持）
- online-mode.html：今回のオンライン版更新
- effects/：共通ファンファーレ処理、カードデータ、演出素材

設置方法
GitHub Pagesのリポジトリで index.html、online-mode.html、effectsフォルダを同じ構成でアップロードしてください。
